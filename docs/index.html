Write mods for OpenFairway

C# on .NET 8, running inside your own offline copy of PGA TOUR 2K25.

Source on GitHubExample modsDownload

Overview

OpenFairway mods are small C# libraries for .NET 8. A mod is one DLL and a mod.json in its own folder under <game>\OpenFairway\mods\. The launcher and the in-game mod manager list every mod with an on/off switch.

LanguageC#, .NET 8
A mod isOne DLL + mod.json
It can useMenus, popups, custom screens, courses, game objects
RunsOffline, in memory only

How a mod gets loaded

Steam starts PGA TOUR 2K25 (only from the OpenFairway launcher does the loader switch on)
  Unity Doorstop (version.dll) starts .NET 8 inside the game process
    OpenFairway.Core
      offline guard     the game cannot reach 2K's servers, or OpenFairway stays inactive
      runtime bridge    talks to the game through its own IL2CPP runtime (il2cpp_* exports)
      type dump         writes OpenFairway\dump\*.cs: every game class, field and method signature
      mod loader        loads mods\<Name>\<Name>.dll and calls OnLoad on its IFairwayMod

Nothing on disk is changed: the game files stay as Steam installed them, and all changes live in memory for one session. Without the launcher, the game starts normally and online.

Your first mod

Implement IFairwayMod: an Id, and OnLoad, which runs once when the game is up. Everything the platform offers comes in through IModContext.

examples/HelloBanner/HelloBanner.cs
using OpenFairway.API;

namespace Examples;

/// <summary>The smallest useful mod: restyles the main menu's banner and shows a popup when it is selected.</summary>
public sealed class HelloBanner : IFairwayMod
{
    public string Id => "example.hellobanner";

    public void OnLoad(IModContext ctx)
    {
        ctx.Ui.MainMenu.SetBanner(new MenuBanner
        {
            Title = "HELLO",
            Subtitle = "MY FIRST MOD",
            CoursePhoto = true,          // one of the game's course photos behind the title
            CalloutLabel = "SAY HI",     // the prompt in the banner's corner
            OnClick = () => ctx.Ui.ShowNotice("HELLO", "This popup comes from a mod."),
        });
        ctx.Log.Info("Hello from a mod");
    }
}

Next to the DLL goes a mod.json. The icon is the name of one of the game's own interface sprites; the mod manager shows the rest.

mod.json
{
  "name": "Hello Banner",
  "version": "1.0.0",
  "author": "You",
  "description": "The smallest useful mod.",
  "icon": "Icon_Play"
}

Build and install

A mod project only needs .NET 8 and a reference to OpenFairway.API.dll, which ships with OpenFairway in <game>\OpenFairway\core\. The examples in this repo use examples/Directory.Build.props instead; copy one of them to start.

HelloBanner.csproj
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
    <EnableDynamicLoading>true</EnableDynamicLoading>
  </PropertyGroup>
  <ItemGroup>
    <!-- Private=false: the game already loads OpenFairway.API.dll; never ship your own copy. -->
    <Reference Include="OpenFairway.API" HintPath="path\to\OpenFairway.API.dll" Private="false" />
  </ItemGroup>
</Project>
Install
dotnet build -c Release
mkdir "<game>\OpenFairway\mods\HelloBanner"
copy bin\Release\HelloBanner.dll "<game>\OpenFairway\mods\HelloBanner"
copy mod.json "<game>\OpenFairway\mods\HelloBanner"

Start the game from the OpenFairway launcher. Logs are in <game>\OpenFairway\logs\openfairway.log, with every line from ctx.Log tagged with your mod's id.

Copy only your DLL and mod.json. A copy of OpenFairway.API.dll in your mod's folder would be a second, different API and the mod would not load.

The main menu

ctx.Ui.MainMenu rebuilds the game's own menu: which tabs show, the tiles on each tab (yours or the game's), and the banner. These are rules the platform keeps applying, because the game rebuilds its menus often, so set them once in OnLoad.

examples/PracticeMenu/PracticeMenu.cs
using System;
using System.Linq;
using OpenFairway.API;

namespace Examples;

/// <summary>Rebuilds the main menu's HOME tab: two of the game's own tiles, a tile that starts nine holes on a
/// random course, and one that opens a choice popup.</summary>
public sealed class PracticeMenu : IFairwayMod
{
    private IModContext _ctx = null!;

    public string Id => "example.practicemenu";

    public void OnLoad(IModContext ctx)
    {
        _ctx = ctx;
        ctx.Ui.MainMenu.SetTabs(MenuTab.Home, MenuTab.Design);
        // HOME fills its slots top-left, bottom-left, top-right, bottom-right.
        ctx.Ui.MainMenu.SetTiles(MenuTab.Home,
            MenuTile.Game(GameTile.QuickPlay),
            MenuTile.Game(GameTile.Training),
            new MenuTile { Label = "QUICK NINE", Description = "Nine holes on a random course.", OnClick = QuickNine },
            new MenuTile { Label = "TIPS", Description = "Something to work on today.", OnClick = Tips });
        // Any text on screen can be rewritten; '*' matches any run of characters.
        ctx.Ui.ReplaceText("OFFLINE*Reconnect*", "Practice mode");
    }

    private void QuickNine()
    {
        var courses = _ctx.Ui.Courses.All.Where(c => c.IsRealCourse && c.Holes == 18).ToList();
        if (courses.Count == 0) return;
        var course = courses[new Random().Next(courses.Count)];
        if (!_ctx.Ui.Courses.OpenMatch(course.Id, MatchHoles.FrontNine))
            _ctx.Ui.ShowNotice("QUICK NINE", $"{course.Name} could not be opened.");
    }

    private void Tips() => _ctx.Ui.ShowChoices("TIPS", "Pick something to practise.", new[]
    {
        new MenuChoice { Label = "PUTTING", Description = "Lag putts from 30 feet.", OnSelect = () => _ctx.Ui.ShowNotice("PUTTING", "Ten putts from 30 feet. Count how many stop inside three feet.") },
        new MenuChoice { Label = "WEDGES", Description = "Hit three distances.", OnSelect = () => _ctx.Ui.ShowNotice("WEDGES", "Hit 50, 75 and 100 yards, five balls each.") },
    });
}

Popups are the game's own too: ShowNotice for a message, ShowChoices for a list, ReplacePopup to rewrite or silence one of the game's popups by its internal name, and ReplaceText for any text on screen.

Two mods setting the same tab's tiles will take turns overwriting each other. The bundled Offline Main Menu mod owns the HOME tab; switch it off while you try a menu example.

Custom screens

ctx.Ui.CreateScreen() gives you a full screen drawn with the engine's UI components in the game's own fonts, on a fixed 1920x1080 canvas that the platform scales to the window. It handles the mouse, keyboard and gamepad (with a focus ring), Escape/B for back, and blocks the game's input while it is open. The Climb and the mod manager are built this way.

You draw the whole screen in Render and call Invalidate() when something changes. Each draw builds the page again; numbers, meters and Slide fills remember their last value by key and animate to the new one.

examples/CourseBrowser/CourseBrowser.cs
using System.Linq;
using OpenFairway.API;

namespace Examples;

/// <summary>A full custom screen: the game's courses as photo cards, eight to a page. Selecting one starts nine
/// holes on it. Shows drawing on the canvas, entrance animation, buttons, paging and starting a match.</summary>
public sealed class CourseBrowser : IFairwayMod
{
    // Colours are 0xRRGGBBAA. These are the game's own menu colours (see docs/design.md).
    private const uint Bg = 0x0F0F1DFFu, Tile = 0x242731FFu, TileHover = 0x2E323DFFu, Text = 0xF4F4F4FFu, Muted = 0xAEB4C6FFu;
    private const int PerPage = 8;

    private IModContext _ctx = null!;
    private IUiScreen _screen = null!;
    private int _page;

    public string Id => "example.coursebrowser";

    public void OnLoad(IModContext ctx)
    {
        _ctx = ctx;
        _screen = ctx.Ui.CreateScreen();
        _screen.Render = Draw;           // called on open, after Invalidate, and when the window is resized
        _screen.OnBack = _screen.Close;  // Escape or B
        ctx.Actions.Register("coursebrowser.open", Open);
        ctx.Ui.MainMenu.SetTiles(MenuTab.Home,
            new MenuTile { Label = "COURSES", Description = "Every course, offline.", OnClick = Open },
            MenuTile.Game(GameTile.QuickPlay));
    }

    private void Open()
    {
        _page = 0;
        _screen.Open();
    }

    private void Draw(IUiCanvas c)
    {
        var courses = _ctx.Ui.Courses.All.OrderBy(course => course.Name).ToList();
        var pages = (courses.Count + PerPage - 1) / PerPage;

        // The canvas is always 1920x1080; the platform scales it to the window.
        c.Rect(0, 0, 1920, 1080, Bg);
        c.Label(80, 56, 1200, 70, "COURSES", 56, Text, UiAlign.Left, heading: true);
        c.Label(84, 126, 1200, 34, $"{courses.Count} courses  ·  page {_page + 1} of {pages}", 22, Muted);

        for (var i = 0; i < PerPage && _page * PerPage + i < courses.Count; i++)
        {
            var course = courses[_page * PerPage + i];
            float x = 80 + i % 4 * 450, y = 200 + i / 4 * 380;
            // Everything drawn inside a group fades and rises in together, here one card after another.
            using (c.Group(delay: i * 0.04f, rise: 14))
            {
                c.Clickable(x, y, 430, 360, () => Play(course), Tile, TileHover, radius: 4);
                if (_ctx.Ui.Courses.Thumbnail(course.Id) is { } photo) c.Image(x, y, 430, 250, photo, radius: 4);
                c.Label(x + 20, y + 262, 390, 40, course.Name.ToUpperInvariant(), course.Name.Length > 24 ? 18 : 22, Text, UiAlign.Left, heading: true);
                c.Label(x + 20, y + 304, 390, 30, $"Par {course.Par}  ·  {course.Holes} holes", 18, Muted);
            }
        }

        c.Button(80, 980, 220, 60, "PREVIOUS", () => Turn(-1, pages), Tile, TileHover, Text, 22, radius: 4);
        c.Button(320, 980, 220, 60, "NEXT", () => Turn(1, pages), Tile, TileHover, Text, 22, radius: 4);
    }

    private void Turn(int by, int pages)
    {
        _page = (_page + by + pages) % pages;
        _screen.Invalidate(animate: true); // redraw, playing the entrance again
    }

    private void Play(CourseInfo course)
    {
        _screen.Close(); // matches start from the main menu
        if (!_ctx.Ui.Courses.OpenMatch(course.Id, MatchHoles.FrontNine))
            _ctx.Ui.ShowNotice("COURSES", $"{course.Name} could not be opened.");
    }
}

What the canvas draws

CallFor
Rect, Panel, Outline, Gradient, ShadowShapes. Colours are 0xRRGGBBAA.
Label, NumberText in the game's body or heading font; numbers count to new values.
Image, Picture, Backdrop, Icon, SpriteCourse photos, your PNGs, a slowly drifting backdrop, the game's own icons.
Button, Clickable, HintThings to click, with hover, press, keyboard focus and tooltips.
Group, Slide, Meter, RingEntrance animation, a fill that glides between rows, progress.
The game draws its interface in linear colour space, so translucent white shows up as mid grey. Use opaque colours for fills and keep translucent layers dark.

Courses and matches

ctx.Ui.Courses lists the courses that ship with the game, read from its own data at run time: name, par, holes, length, difficulty and its preview photo. OpenMatch opens the game's local match screen on a course, ready to begin; call it with the main menu in front.

var course = ctx.Ui.Courses.All.First(c => c.Name.Contains("St Andrews"));
ctx.Ui.Courses.OpenMatch(course.Id, MatchHoles.FrontNine);

Mods working together

ctx.Actions lets a mod offer something by name, and any other mod call it without referencing its DLL. Invoke returns false when nobody offers the action, so a feature can say which mod to switch on.

// In one mod
ctx.Actions.Register("coursebrowser.open", Open);

// In another
if (!ctx.Actions.Invoke("coursebrowser.open"))
    ctx.Ui.ShowNotice("COURSES", "Switch on the Course Browser mod.");
ActionOffered byDoes
career.openOffline CareerOpens the game's MyCAREER offline
player.openOffline CareerOpens MyPLAYER
player.addxp nOffline CareerGives the golfer n MyPLAYER experience
player.addequipmentxp nOffline CareerGives the active golf bag n club and ball experience
mods.openOffline Main MenuOpens the in-game mod manager
climb.openThe ClimbOpens The Climb

Timing, saving and game objects

Game objects may only be touched on the game's main thread. ctx.MainThread gives you a per-frame Update, a Quitting event for saving, and Post to get onto the main thread from anywhere. ctx.DataDirectory is a folder for your mod's files.

ctx.Runtime reaches the game itself: find classes and methods by name, call them, read and write fields. What exists is listed in <game>\OpenFairway\dump\*.cs, which the platform writes from the running game (signatures only, no code). This example uses all three.

examples/RoundCounter/RoundCounter.cs
using System;
using System.Collections.Generic;
using System.IO;
using System.Text.Json;
using OpenFairway.API;

namespace Examples;

/// <summary>Counts the rounds you finish and keeps the count between sessions. Shows a per-frame tick on the
/// game's main thread, reading the game's own objects through the runtime, saving data, and offering an action
/// other mods can call.</summary>
public sealed class RoundCounter : IFairwayMod
{
    private IModContext _ctx = null!;
    private readonly HashSet<string> _seen = new();
    private string _savePath = "";
    private int _rounds;
    private bool _primed;
    private long _nextCheck;
    private IntPtr _getScorecards;

    public string Id => "example.roundcounter";

    public void OnLoad(IModContext ctx)
    {
        _ctx = ctx;
        _savePath = Path.Combine(ctx.DataDirectory, "rounds.json");
        if (File.Exists(_savePath)) _rounds = JsonSerializer.Deserialize<int>(File.ReadAllText(_savePath));

        ctx.MainThread.Update += Tick;    // once per rendered frame, on the game's main thread
        ctx.MainThread.Quitting += Save;  // the last chance to save
        ctx.Actions.Register("roundcounter.show", () =>
            ctx.Ui.ShowNotice("ROUNDS", $"You have finished {_rounds} rounds with this mod on."));
    }

    private void Tick()
    {
        if (_ctx.MainThread.Frame < _nextCheck) return;
        _nextCheck = _ctx.MainThread.Frame + 60; // about once a second is plenty

        // The game's classes and methods are found by name. OpenFairway\dump\*.cs lists everything that exists.
        var rt = _ctx.Runtime;
        if (_getScorecards == IntPtr.Zero)
        {
            var scorecard = rt.FindClass("HB.Golf", "", "Scorecard");
            if (scorecard == IntPtr.Zero) return;
            _getScorecards = rt.FindMethod(scorecard, "GetScorecards", 0);
            if (_getScorecards == IntPtr.Zero) return;
        }

        foreach (var card in rt.ReadArray(rt.Invoke(_getScorecards, IntPtr.Zero)))
        {
            if (card == IntPtr.Zero) continue;
            var klass = rt.GetClass(card);
            var id = rt.ReadString(rt.GetField<IntPtr>(card, klass, "_id"));
            var complete = rt.GetField<byte>(card, klass, "complete") != 0;
            if (id == null || !complete || !_seen.Add(id) || !_primed) continue;
            _rounds++;
            _ctx.Log.Info($"Round finished: {_rounds} so far.");
            Save();
        }
        _primed = true; // rounds already finished when the game started are not new
    }

    private void Save() => File.WriteAllText(_savePath, JsonSerializer.Serialize(_rounds));
}
Handles are raw pointers into the game. Do not keep the game's objects between frames unless you pin them (Runtime.Pin): the game's garbage collector does not know about your references. Pass only pointers you got from the runtime; a wrong pointer crashes the game.

Rules

  • Offline only. Mods run only when the game was started from the OpenFairway launcher and cannot reach 2K's servers.
  • Nothing paid. No VC, store items, passes or DLC. Mods that unlock paid content are out of scope and are not accepted.
  • Memory only. Never change, replace or redistribute the game's files, and never share dump output or game assets.

void Glow(float x, float y, float w, float h, uint rgba)

void Ring(float x, float y, float size, float thickness, string key, float fraction, uint fill, uint back)

A photo that fills the box and drifts slowly (a gentle zoom and pan), for backdrops. Give a game or platform image, or a file path; the image wins when both are given.

void Pulse(float x, float y, float w, float h, uint rgba, float radius = 12)

A soft halo around a box that slowly breathes, to draw the eye to the next thing to do. Draw it before the box.

Text drawn until the returned scope is disposed casts a soft shadow, for legibility over photos.
